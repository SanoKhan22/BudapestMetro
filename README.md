# BudapestMetro 🚇

A JavaScript-based quiz game to test your knowledge of Budapest's metro system!

## About the Game

Budapest Metro Quiz is an interactive web-based game where players test their knowledge about the four metro lines of Budapest (M1, M2, M3, and M4) and their stations. The game features various question types and difficulty levels.

## Features

- **Multiple Question Types**: 
  - Identify which metro line a station belongs to
  - Recognize stations on specific lines
  - Identify terminal stations
  
- **Three Difficulty Levels**:
  - Easy: 5 questions
  - Medium: 10 questions
  - Hard: 15 questions

- **Score Tracking**: Keep track of your score, current streak, and best streak
- **Educational**: Learn about Budapest's metro system while playing
- **Responsive Design**: Works on desktop and mobile devices

## Budapest Metro Lines

- **M1 (Yellow Line)**: The oldest metro line in continental Europe, opened in 1896
- **M2 (Red Line)**: Runs east-west, connecting major transportation hubs
- **M3 (Blue Line)**: The busiest line, running north-south through the city
- **M4 (Green Line)**: The newest line, opened in 2014

## How to Play

1. Open `index.html` in your web browser
2. Select your preferred difficulty level
3. Click "Start Game"
4. Answer questions about Budapest metro stations
5. Try to get the highest score possible!
